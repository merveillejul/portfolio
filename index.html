Veille Technologique

Suivi régulier des évolutions en sécurité web et développement fullstack.

Définition

La veille technologique est un processus continu de surveillance des évolutions du domaine informatique, permettant d'anticiper les changements et d'adapter ses pratiques de développement.

Mon sujet

La sécurité des applications web et les nouvelles pratiques de développement fullstack : frameworks modernes, CI/CD, authentification, protection des données.

Méthode

Consultation régulière des documentations officielles (Laravel, React, OWASP, CERT-FR), des blogs techniques (Dev.to, MDN Web Docs) et des changelogs GitHub des projets utilisés.

OWASP CERT-FR MDN Web Docs Laravel Blog React Blog Dev.to GitHub Changelogs

Fiches de veille

owasp.org · 6 nov. 2025

OWASP Top 10:2025 — Nouvelles catégories de failles

L'OWASP Top 10:2025 actualise la liste des vulnérabilités les plus critiques des applications web, avec deux nouvelles catégories : A03 Software Supply Chain Failures et A10 Mishandling of Exceptional Conditions.

SécuritéSQL InjectionXSS
Apport projet : Appliqué dans ProjectFlow : requêtes préparées PDO (anti-injection), hashage bcrypt, headers de sécurité X-Frame-Options et X-Content-Type-Options.
owasp.org/Top10/2025/
reverb.laravel.com · 12 mars 2024

Laravel Reverb — Serveur WebSocket officiel Laravel

Lancé avec Laravel 11, Reverb est le serveur WebSocket haute performance et open-source de Laravel. Il remplace les solutions externes comme Pusher pour les communications en temps réel : notifications, chat, tableaux de bord live.

LaravelWebSocketTemps réel
Apport projet : Intégré dans ProjectFlow pour les notifications en temps réel entre membres d'équipe, sans dépendance externe payante.
reverb.laravel.com
react.dev · 5 déc. 2024

React v19 — Actions, nouveaux hooks et Server Components

React 19 introduit les Actions pour simplifier les mutations de données, de nouveaux hooks (useActionState, useOptimistic, useFormStatus) et le support natif des React Server Components avec gestion des métadonnées.

ReactFront-endPerformance
Apport projet : Utilisé dans l'interface web de ProjectFlow. Les Actions React 19 simplifient la gestion des formulaires de création de tâches et projets.
react.dev/blog/2024/12/05/react-19
docs.github.com · janv. 2026

GitHub Actions — Automatisation CI/CD par fichiers YAML

GitHub Actions permet d'automatiser les workflows de développement directement dans le dépôt. Les pipelines définis en YAML se déclenchent à chaque push : tests automatiques, build et déploiement sans intervention manuelle.

CI/CDGitHub ActionsAutomatisation
Apport projet : Configuré sur ProjectFlow (déploiement Railway + Vercel) et AnimAmi (synchronisation FTP automatique vers Hostinger à chaque push).
docs.github.com/en/actions
laravel.com/docs · janv. 2026

Laravel Sanctum — Authentification légère par token API

Sanctum fournit un système d'authentification par token pour les SPAs, applications mobiles et APIs. Chaque utilisateur peut générer plusieurs tokens avec des capacités spécifiques (scopes). Les tokens peuvent être révoqués à tout moment.

AuthentificationAPI RESTToken
Apport projet : Utilisé dans l'API ProjectFlow. Tokens d'une durée de vie de 2h, révocation automatique à la déconnexion, compatible avec l'app web et l'app mobile.
laravel.com/docs/sanctum
docs.expo.dev · mars 2026

EAS Build — Compilation APK/IPA React Native dans le cloud

EAS (Expo Application Services) Build est un service hébergé qui compile les projets React Native en APK Android ou IPA iOS directement dans le cloud. Il gère automatiquement les certificats de signature et fonctionne sans Android Studio.

React NativeMobileExpo
Apport projet : Utilisé pour générer l'APK Android de ProjectFlow Mobile. Le fichier APK est disponible en téléchargement direct depuis Expo.
docs.expo.dev/build/introduction
