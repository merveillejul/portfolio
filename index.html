Veille Technologique

Suivi régulier des évolutions en sécurité web et développement fullstack.

Définition

La veille technologique est un processus continu de surveillance des évolutions du domaine informatique, permettant d'anticiper les changements et d'adapter ses pratiques de développement.

Mon sujet

La sécurité des applications web et les nouvelles pratiques de développement fullstack : frameworks modernes, CI/CD, authentification, protection des données.

Méthode

Consultation régulière des documentations officielles (Laravel, React, OWASP, CERT-FR), des blogs techniques (Dev.to, MDN Web Docs) et des changelogs GitHub des projets utilisés.

OWASP CERT-FR MDN Web Docs Laravel Blog React Blog Dev.to GitHub Changelogs
